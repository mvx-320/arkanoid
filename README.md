# Arkanoid
#ArcadeGame #Bricks
Study Project in **Introduction to Game Programming**
In multiple Exercises we are programming Arkanoid.
## Input
### Actions & Default Bindings
| Action | Keys | Discription |
| --- | --- | --- |
| `MoveLeft` | $\leftarrow$ / `A` / GamePad left stick to the left | Move paddle to the left |
| `MoveRight` | $\rightarrow$ / `D` / GamePad left stick to the right | Move paddle to the right |
| `LaunchBall` | `Space` / GamePad south button | Begins game by launching the ball | 
| `MouseLeft` | Left Mouse button | Toggles between **Button Conrtol** and **Mouse Control**. |
